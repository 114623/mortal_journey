# 无限仙途
对wangkkkkkkkk的工作做了一些改动，开这个仓库只是为了把项目部署到 GitHub Pages 。小孩子啥都不懂用ai做着玩的，有问题骂ai别骂我

基于 OpenAI 兼容大语言模型（LLM）驱动的浏览器文字 RPG。单页 Vue 3 + Vite + TypeScript 应用，讲述凡人踏入修仙界、一路修炼成长的故事。所有叙事由 AI 实时生成，配合回合制战斗、境界突破与 NPC 交互。

- 在线体验： https://114623.github.io/mortal_journey/

- 源：<https://github.com/Wangkkkkkkkk/mortal_journey>

改动内容
人物系统
- 增加凡人境界
- 主角与 NPC 新增「性格 / 外貌 / 记忆」画像，AI 逐回合维护；玩家保存即锁定不被覆写。
- 新增人物档案总览：全部角色列表，按在场/休眠/离开/已故分组。
- 回合中修改画像/世界设定进「待应用队列」，回合结束后统一落地，随存档持久化。
- NPC 卡可删除（二次确认），可编辑 名字/性别/年龄/寿元/境界/灵根；改境界自动重算属性、血量与功法层数。
- 记忆超 1000 字自动由 AI 压缩至约 700 字。
物品与数值
- 给法宝、功法、丹药加了阶层
- 阶层系统覆盖全品类：法宝跨阶压制 0.65^Δ；低阶丹药对高一阶修士效果 1/5；材料异阶同炉拒绝；功法境界高于阶层后不再产修为。
- 凡人阶物品练气期剩 10%，筑基起归零；凡人兵器/武功一律从图鉴取用。
- 品阶约束：NPC 按战力档限品阶区间，主角不限制；AI 显式 grade 优先。
- 境界表化神段重平衡：按元婴后期基数 ×1.25/1.5/1.75 重排，消除顶部趋平。
战斗
- 法宝/功法/丹药阶层压制接入战斗引擎，含战斗内服药链路。
界面
- 天道编辑（原物品锻造）：主角与 NPC 的法宝/功法/储物袋均可改品级、阶层、词条、效果，支持角色间转移，改动即时生效落盘。
- 世界设定界面：世界观/规则/预设三段编辑，支持恢复默认。
- 游戏内读取人生：读取/导出/删除，切换前自动落盘。
- 回合自动存档：每回合快照，滚动保留 0–10 份（默认 3），配额不足自动丢最旧。
- 侧边栏新增各入口（带待应用角标）。
AI 与提示词
- 预设拆分：输出契约固定，世界观/规则/状态模板可编辑；剧情与状态 AI 共用世界观。
- 合并外部预设「双星纪 V1.1」（文风、对白、反全知、叙事约束等）；NSFW 系列未合并，已导出为 txt。
- NPC 一致性校验：正文境界与 NPC 卡冲突时就地纠正，零额外 token。
- 每回合新登场有名 NPC 限 1~10 人；世界设定注入全部五个生成链路。
